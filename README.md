# Landing Venezuela - ingresos desde el telefono

Pagina unica de captacion: un boton que manda al grupo de WhatsApp.

- `public/index.html`: toda la landing (HTML + CSS inline, sin JS).
- Render: sitio estatico gratis, publica la carpeta `public/`.
- Cambiar el grupo: editar el `href` del boton `.cta` en `public/index.html`.
